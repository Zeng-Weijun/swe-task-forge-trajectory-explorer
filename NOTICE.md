# Attribution

The explorer UI in `docs/` is **not original work**. It is vendored from
Empiria Labs' public Trajectory Explorer at <https://empiriaai.github.io/trajectory-explorer.html>
so that this dataset can be browsed without a backend.

| File | Origin | Modified |
|---|---|---|
| `docs/style.css`, `docs/fonts.css`, `docs/script.js`, `docs/favicon.svg` | empiriaai.github.io | no |
| `docs/fonts/*.woff2` | Space Grotesk, Inter Tight, JetBrains Mono (SIL OFL) | no |
| `docs/index.html` | empiriaai.github.io | yes — single SWE category, feedback panels repurposed as a provenance panel, feedback data scripts removed |
| `docs/trajectory-explorer.js` | empiriaai.github.io | yes — see below |
| `docs/trajectory-dialogue.{html,css,js}` | <https://github.com/Zeng-Weijun/trajectory-viewer> (own work, built on the same upstream) | yes — embed mode, SWE branding, feedback snapshot index dropped |
| `docs/swe-fork.css` | this project | — |
| `docs/trajectory-data.js` | this project | generated by `tools/export_explorer_data.py` |

Changes to `trajectory-explorer.js`:

1. default category `feedback` → `swe`;
2. empty sidebar categories are skipped;
3. `renderSweProvenance()` added — drives the (feedback-only) pipeline panel from
   mining-manifest fields;
4. the upstream SWE task/verification panels contain hard-coded demo values
   (`'2019-03-24'`, `'django/template/engine.py'`, `'test_autoescape_off'`,
   `'Patch exists': 'true'`, `'Exception': 'None'`); these are replaced with real
   per-run fields;
5. `runSubtitle` shows `repo · task · shape` instead of the whole instruction;
6. empty sidebar categories are skipped and the initial selection is the richest
   solved run rather than index 0.

Changes to `trajectory-dialogue.html`:

1. `?embed=1` hides its own topbar so the explorer can iframe it, and Escape
   posts `empiria-exit-timeline-fullscreen` back to the parent;
2. the feedback snapshot index is no longer loaded (this corpus is inline).

The upstream site publishes no licence. These assets are vendored for evaluation
of this dataset; on request they can be removed and replaced with a plain
renderer — `docs/trajectory-data.js` and the exporter are the only original
artifacts and carry no dependency on the vendored UI.
